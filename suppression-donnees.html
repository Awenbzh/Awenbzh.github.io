Demande de suppression des données – Breizh Plage

Breizh Plage, éditée par Awen ha Fredrig Studio, ne nécessite pas la création d’un compte utilisateur.

Certaines données peuvent néanmoins être traitées dans le cadre de l’utilisation de l’application et de ses services.

Comment demander la suppression de vos données

Pour demander la suppression des données personnelles vous concernant, envoyez votre demande à :

contact@awenhafredrigstudio.bzh

Indiquez dans votre message :

  • que votre demande concerne l’application Breizh Plage ;
  • les informations permettant d’identifier les données concernées ;
  • la nature de votre demande de suppression.

Données pouvant être supprimées

Lorsque les données peuvent être associées à l’utilisateur, elles sont supprimées dans la mesure où aucune obligation légale ou réglementaire n’impose leur conservation.

Les données enregistrées uniquement localement sur l’appareil, par exemple certaines informations du journal ou des préférences locales, peuvent être supprimées en effaçant les données de l’application ou en désinstallant Breizh Plage.

Données traitées par des services tiers

Certaines données peuvent être traitées par des services tiers utilisés par l’application, notamment Google AdMob pour la publicité dans la version gratuite.

Les données traitées par ces services sont soumises à leurs propres règles de confidentialité et aux choix de consentement de l’utilisateur.

Délai de traitement

Les demandes sont traitées dans les meilleurs délais, conformément aux obligations applicables en matière de protection des données personnelles.
